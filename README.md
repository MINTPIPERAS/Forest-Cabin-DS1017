# 林间灯暖 · Mistwood Cabin

一个纯程序化的 Three.js 森林木屋场景，围绕「秋日蓝调时刻、薄雾、暖灯」设计。没有外部模型和图片资源，木屋、松林、地面覆盖物、材质与炊烟都由代码生成。

## 运行

不需要安装依赖或打包，直接启动一个静态服务器：

```bash
python -m http.server 4173
```

然后打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。场景需要支持 WebGL 2 的浏览器。

## 交互

- **拖动**：环视木屋与森林；**滚轮 / 双指**：拉近或拉远。
- 空闲片刻后镜头会缓慢漂移，适合作为沉浸式展示。
- 右下角按钮可切换**环境声**（程序化风声、虫鸣与炉火轻响）和**深夜模式**，也可以进入全屏。
- 进入场景时镜头会有一个很慢的推近动作；拖动即可接管镜头。

## 实现要点

- 原生 ES Modules + 本地内置的 Three.js r160，无构建步骤。
- Canvas 生成树皮、木板、石墙、瓦片、地面与窗内暖光等材质。
- 松树枝叶使用程序化针叶卡片，秋树使用实例化叶簇和落叶。
- 静态木屋与地面细节按材质合并，以降低绘制调用；阴影烘焙后只更新一次。
- 自制天空/雾/调色 Shader，搭配 UnrealBloom、电影颗粒、暗角和轻微色散。
- 支持桌面与手机竖屏的响应式构图。
- 推荐配合声音体验；音效完全由 Web Audio 实时合成，默认关闭。
